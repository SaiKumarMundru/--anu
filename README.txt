FOR ANUU — THREE-PAGE GITHUB PAGES WEBSITE

Files:
- index.html: opening page and first music player
- apology.html: apology letter, memory photos, floating stickers and second player
- promises.html: expandable promises and third player
- style.css: shared design and photo backgrounds
- script.js: floating stickers and interactive promises

PUBLISH FROM YOUR PHONE
1. Create a GitHub repository, e.g. for-anuu.
2. Upload all files and folders while preserving their names and structure.
3. Open repository Settings → Pages.
4. Choose “Deploy from a branch”, select branch main and folder /(root), then Save.
5. Wait for deployment and open the URL shown in Settings → Pages.
6. Test each page, photo and music player on your phone.

PRIVACY
GitHub Pages is public. Anyone with the URL may be able to see the website and photos. Upload only images you are comfortable publishing.

The floating teddy is a generic emoji, not a Winnie-the-Pooh asset. Use licensed GIFs or original artwork if you want specific characters.
